# HoopsPass NBA ticket sales — data dictionary

Synthetic dataset for the Xebia webinar *Databricks: Conversational Analytics for Business Teams* (season 2025-26, fictional operator **HoopsPass Inc.**, real NBA teams and arenas as public reference data). Generated by `generator/nba_tickets_generator.py`; every number below is for `--scale 1.0 --seed 2026`.

| Table | Rows |
|---|---|
| `teams` | 30 |
| `arenas` | 30 |
| `games` | 1,325 |
| `customers` | 306,000 |
| `orders` | 2,222,881 |
| `tickets` | 7,279,785 |
| `ref_codes` | 33 |

## Tables

### `teams`

The 30 NBA teams. One row per team. HoopsPass sells tickets on behalf of the HOME team: 'tickets sold for the Lakers' means tickets for games where the Lakers are the home team. sales_region is the HoopsPass regional sales territory used for row-level security.

| Column | Meaning |
|---|---|
| `team_id` | Surrogate key. |
| `team_code` | Official 3-letter code, e.g. LAL, GSW, NYK. |
| `team_name` | Full name, e.g. 'Los Angeles Lakers'. Users also say the nickname ('Lakers') or the code ('LAL'). |
| `city` | Market/city as used in the team name (e.g. 'Golden State', 'LA', 'Utah'). |
| `nickname` | Short name fans use: 'Lakers', 'Warriors', 'Knicks'. |
| `state` | US state (or Canadian province for Toronto) of the home arena, 2-letter code. |
| `country` | US or CA (Toronto Raptors). |
| `conference` | East or West. |
| `division` | Atlantic, Central, Southeast, Northwest, Pacific, Southwest. |
| `sales_region` | HoopsPass sales territory: West, Southwest, Midwest, Southeast, Northeast. Drives row-level security. |
| `arena_id` | Home arena (FK arenas.arena_id). |

### `arenas`

NBA arenas (one per team). capacity is the full arena capacity for basketball; HoopsPass sells only an allocation of it (see games.allocated_seats). Toronto (Scotiabank Arena) is in Canada, not in the US.

| Column | Meaning |
|---|---|
| `arena_id` | Surrogate key. |
| `arena_name` | Current commercial arena name (naming rights change often). |
| `city` | Arena city. |
| `state` | 2-letter state/province code. |
| `country` | US or CA. |
| `capacity` | Full basketball seating capacity (approximate). NOT what HoopsPass sells; see games.allocated_seats. |
| `opened_year` | Year the arena opened. |
| `timezone` | IANA time zone of the arena; games.tipoff_local is in this zone. |

### `games`

One row per game of the 2025-26 season: 1,230 regular-season games (REG), 6 play-in games (PLAYIN) and the playoffs (PLAYOFF, rounds R1, R2, CONF_FINALS, FINALS). attendance is the ARENA-WIDE attendance reported by the team (all vendors); HoopsPass tickets are a subset. allocated_seats is the number of seats HoopsPass was contracted to sell for that game; sell-through = primary tickets sold / allocated_seats.

| Column | Meaning |
|---|---|
| `game_id` | Surrogate key. 225xxxxx = regular season, 525xxxxx = play-in, 425xxxxx = playoffs. |
| `season` | Always '2025-26'. 'This season' = the whole table. |
| `game_type` | REG (regular season), PLAYIN, PLAYOFF. Business questions default to ALL game types unless the user says 'regular season' or 'playoffs'. |
| `playoff_round` | NULL for REG; PLAYIN, R1, R2, CONF_FINALS, FINALS otherwise. |
| `game_date` | Local calendar date of the game. 'Games in December' filter on this column; 'sales in December' filter on orders.order_ts instead. |
| `tipoff_local` | Local tip-off time at the arena (see arenas.timezone). |
| `home_team_id` | Home team (FK teams). HoopsPass sells for the home team. |
| `away_team_id` | Visiting team (FK teams). Use only for 'games against X' questions. |
| `arena_id` | FK arenas. |
| `series_game_no` | Game number within a playoff/play-in series (1-7); NULL for REG. |
| `is_national_tv` | True when the game was nationally televised. |
| `home_points` | Final score of the home team. |
| `away_points` | Final score of the away team. |
| `attendance` | Arena-wide attendance reported by the team (ALL vendors). Do not compare with HoopsPass ticket counts. |
| `allocated_seats` | Seats HoopsPass was contracted to sell for this game. Denominator of sell-through. |

### `customers`

HoopsPass customer accounts (CRM). Contains PII (names, email, phone, date_of_birth, home_zip). About 2% of accounts are duplicates from a legacy import (same email, different customer_id, UPPER-CASE names): count PEOPLE with COUNT(DISTINCT lower(email)). date_of_birth = 1900-01-01 means UNKNOWN (legacy sentinel) and must be excluded from any age calculation.

| Column | Meaning |
|---|---|
| `customer_id` | Surrogate key. Duplicated people exist: use lower(email) to count distinct people. |
| `first_name` | PII. |
| `last_name` | PII. |
| `email` | PII. Login/contact email; the de-duplication key (compare in lower case). |
| `phone` | PII. Format '(NPA) 555-01xx' (fictional range). |
| `date_of_birth` | PII. 1900-01-01 = unknown (legacy import sentinel). Exclude it before computing age. |
| `home_state` | 2-letter US state / Canadian province code (e.g. 'FL', not 'Florida'). |
| `home_country` | US or CA. |
| `home_zip` | PII (quasi-identifier). US ZIP or Canadian postal code. |
| `loyalty_tier_code` | HoopsPass Rewards tier: 0 None, 1 Rookie, 2 Starter, 3 All-Star, 4 MVP (see ref_codes). |
| `favorite_team_id` | Self-declared favourite team (FK teams), NULL if not declared. |
| `signup_date` | Account creation date. |
| `marketing_opt_in` | Consent for marketing e-mails. |
| `created_at` | Row creation timestamp (UTC). |

### `orders`

One row per purchase (checkout). An order has 1..N tickets (see tickets). total_usd = subtotal_usd + fees_usd is the amount the customer paid for the WHOLE order: never join it to tickets and sum it (fan-out). Only status = 'COMPLETED' counts as a sale. SEASON orders (order_type = 'SEASON') cover all 41 home games of a team and therefore have game_id NULL; the game is on each ticket.

| Column | Meaning |
|---|---|
| `order_id` | Surrogate key. |
| `customer_id` | FK customers. |
| `game_id` | FK games. NULL for SEASON packages (the game is on each ticket row). |
| `order_type` | SINGLE, GROUP, RESALE or SEASON (see ref_codes). |
| `order_ts` | Purchase timestamp (UTC). 'Sales in <month>' filters on this column. |
| `channel_code` | 1 box office, 2 web, 3 mobile app, 4 phone, 5 resale marketplace, 6 season sales team (see ref_codes). |
| `status` | COMPLETED, REFUNDED, CANCELLED, CHARGEBACK. Only COMPLETED is a sale. |
| `payment_method` | CARD, APPLE_PAY, PAYPAL, GIFT_CARD, NONE (comps). |
| `card_last4` | PII-adjacent: last four digits of the payment card, NULL when not card-based. |
| `promo_code` | Promotion code applied, NULL if none. |
| `ticket_count` | Number of ticket rows in this order (41 for season packages). |
| `subtotal_usd` | Sum of sold_price_usd of the tickets in the order (face value money, passed through to the team). |
| `fees_usd` | HoopsPass service fees for the order incl. a 2.50 USD order processing fee on single/group orders. |
| `total_usd` | Amount paid by the customer = subtotal_usd + fees_usd. Order-level: never sum it after joining tickets. |

### `tickets`

One row per seat per game (the finest grain; 7.3M rows at full scale). This is the table for counting tickets and summing ticket-level money. A ticket is SOLD only when ticket_type_code <> 'COMP' and its order is COMPLETED. RSL rows are fan-to-fan resales outside the HoopsPass allocation: they count for revenue (fee + commission) but not for sell-through. home_team_id is denormalised from games for convenience and row-level security.

| Column | Meaning |
|---|---|
| `ticket_id` | Surrogate key. |
| `order_id` | FK orders. Status and channel live on the order. |
| `game_id` | FK games (always set, also for season-package tickets). |
| `home_team_id` | Home team of the game (denormalised from games; FK teams). Use for 'tickets sold for team X'. |
| `section` | Seating section label. |
| `row_label` | Row label. |
| `seat_number` | Seat number within the row. |
| `price_tier_code` | P1 courtside, P2 lower center, P3 lower ends, P4 club, P5 upper center, P6 upper ends (see ref_codes). |
| `ticket_type_code` | STD standard, SSN season package, GRP group, COMP complimentary (not a sale), RSL resale marketplace (see ref_codes). |
| `face_value_usd` | Printed/list price of the seat for this game, before discounts. Not what was paid. |
| `sold_price_usd` | Price actually paid for the seat (0 for COMP). Average ticket price = AVG(sold_price_usd) over SOLD tickets. |
| `service_fee_usd` | HoopsPass service fee on this ticket (12% + 1.50 primary, 8% season, 10% resale buyer fee). HoopsPass revenue. |
| `commission_usd` | 10% seller commission on resale tickets (RSL only). HoopsPass revenue. |
| `scanned_at` | Entry scan timestamp; NULL = not scanned (no-show, or voided ticket). |

### `ref_codes`

Lookup table decoding every *_code column (channel_code, ticket_type_code, price_tier_code, loyalty_tier_code, order_status, order_type, game_type). Join on code_type + code.

| Column | Meaning |
|---|---|
| `code_type` | Which column the code belongs to, e.g. 'ticket_type_code'. |
| `code` | The code value as stored in the fact tables (string). |
| `label` | Short human label. |
| `description` | Full business meaning. |

## Business definitions (the semantic layer the SME encodes in Genie)

| Metric | SQL (over `v_ticket_sales`) | Meaning |
|---|---|---|
| **Tickets sold** | `SUM(CASE WHEN is_sold THEN 1 ELSE 0 END)` | Count of SOLD tickets: order COMPLETED and ticket_type_code <> 'COMP'. Includes resale (RSL) unless asked for sell-through. |
| **Primary tickets sold** | `SUM(CASE WHEN is_sold AND ticket_type_code <> 'RSL' THEN 1 ELSE 0 END)` | Sold tickets inside the HoopsPass allocation (no RSL). Numerator of sell-through. |
| **GMV** | `SUM(CASE WHEN is_sold THEN sold_price_usd + service_fee_usd ELSE 0 END)` | Total value paid by fans for sold tickets (face money + HoopsPass fees). NOT HoopsPass revenue. |
| **Net revenue** | `SUM(CASE WHEN is_sold THEN service_fee_usd + commission_usd ELSE 0 END)` | What HoopsPass books: service fees + resale commissions on sold tickets. Face value is passed through to the team. |
| **Average ticket price** | `AVG(CASE WHEN is_sold AND ticket_type_code <> 'RSL' THEN sold_price_usd END)` | Average price PAID per sold primary ticket (excludes comps and resale). |
| **Sell-through rate** | `SUM(primary_tickets_sold) / NULLIF(SUM(allocated_seats), 0)` | Defined on v_game_sales (game grain): primary tickets sold / allocated seats. Never compute it on ticket rows. |
| **No-show rate** | `SUM(CASE WHEN is_sold AND scanned_at IS NULL THEN 1 ELSE 0 END) / NULLIF(SUM(CASE WHEN is_sold THEN 1 ELSE 0 END), 0)` | Share of sold tickets that were never scanned at the gate. |
| **Comps** | `SUM(CASE WHEN ticket_type_code = 'COMP' AND order_status = 'COMPLETED' THEN 1 ELSE 0 END)` | Complimentary tickets issued. Not sales. |

| Filter | SQL | Meaning |
|---|---|---|
| **Sold tickets** | `is_sold` | Order COMPLETED and not complimentary. |
| **Regular season** | `game_type = 'REG'` | Regular-season games only. |
| **Playoffs** | `game_type IN ('PLAYIN', 'PLAYOFF')` | Play-in and playoff games. |
| **Primary tickets** | `ticket_type_code <> 'RSL'` | Tickets inside the HoopsPass allocation. |
| **Resale tickets** | `ticket_type_code = 'RSL'` | Resale marketplace tickets. |
| **Known date of birth** | `date_of_birth <> DATE '1900-01-01'` | Excludes the legacy 1900-01-01 sentinel. |

| Field | SQL | Meaning |
|---|---|---|
| **Home team** | `home_team_name` | The team HoopsPass sold the ticket for (home side). |
| **Game month** | `DATE_TRUNC('month', game_date)` | Calendar month of the game date. |
| **Sales month** | `DATE_TRUNC('month', order_ts)` | Calendar month of the purchase. |
| **Price tier** | `price_tier_label` | Decoded price tier (Courtside ... Upper ends). |
| **Ticket type** | `ticket_type_label` | Decoded ticket type. |
| **Sales channel** | `channel_label` | Decoded sales channel. |
| **Customer age** | `CASE WHEN date_of_birth <> DATE '1900-01-01' THEN DATEDIFF(YEAR, date_of_birth, DATE '2026-06-30') END` | Age at season end, NULL when DOB unknown. |
| **Loyalty tier** | `CASE loyalty_tier_code WHEN 0 THEN 'None' WHEN 1 THEN 'Rookie' WHEN 2 THEN 'Starter' WHEN 3 THEN 'All-Star' WHEN 4 THEN 'MVP' END` | Decoded HoopsPass Rewards tier. |

## Traps built into the data (and which configuration layer fixes each)

| # | Trap | How the raw agent fails | What fixes it in the curated agent |
|---|---|---|---|
| T1 | Coded columns (`channel_code`, `ticket_type_code`, `price_tier_code`, `loyalty_tier_code`) with no meaning in the raw tables | Guesses what codes mean, or reports codes | UC column comments, `ref_codes` join baked into `v_ticket_sales`, Fields with CASE decoding |
| T2 | Grain and fan-out: `orders.total_usd` is order-level; `games.attendance` is arena-wide; SEASON orders have `game_id` NULL | Joins orders to tickets and sums totals (x2.6); compares attendance with ticket counts; loses season tickets when joining through `orders.game_id` | Table comments, pre-joined view, Measures defined on ticket grain, join relationships with cardinality |
| T3 | Home vs away: tickets are sold for the HOME team | Joins on either team (doubles the count) or on the away team | Comment on `teams`, `home_team_id` on tickets, Field *Home team*, example query |
| T4 | Business definitions: *sold* (COMPLETED, no COMP), *revenue* (net vs GMV), *average price* (sold price, primary only), *sell-through* (sold / allocated), *no-show* (unscanned among sold) | Counts every row; sums face value; reports GMV as revenue; divides by capacity | Measures and Filters (SQL expressions), trusted example queries, clarification rule in general instructions |
| T5 | Dirty data: `date_of_birth` = 1900-01-01 sentinel (~12%), ~2% duplicate customers, Toronto outside the US | Average age 58 instead of 47.5; over-counts people; 30 US arenas | Column comment, Filter *Known date of birth*, people counted by `lower(email)`, `country` column |
| T6 | PII and territories | Prints names, e-mails, phones, DOB, card digits; every user sees every region | Columns hidden in the agent AND masked in Unity Catalog; row filter on `sales_region` via `home_team_id` |

## Dates and conventions

Regular season 2025-10-21 … 2026-04-12 (All-Star break 2026-02-13 … 02-18, no games on 12-24, five games on 12-25); play-in 2026-04-14 … 04-17; playoffs from 2026-04-18 with rounds chained 2 days apart; data cut-off 2026-06-30. Season packages went on sale 2025-08-04, single-game tickets 2025-09-15. `order_ts` is UTC, `tipoff_local` is arena local time. Phones use the fictional 555-01xx range and e-mails the reserved example.com/.net/.org domains.
